# Roadmap

## Current status

The command-line application is functional and stores all journal data in portable Markdown files.

The project currently includes:

* Daily task, note and event management
* Task completion, reopening, cancellation and migration
* Journal browsing and searching
* Previous-day review
* Pending-task listing
* Backup and restore functionality
* Daily task statistics
* Completion percentage and progress bar
* Automated unit tests
* Continuous integration with GitHub Actions
* Project documentation

## Version 1.0 goals

The following work remains before the command-line version is considered complete:

* Review the terminal interface for consistency
* Review user-facing error messages
* Perform a final manual test of every menu option
* Confirm all automated tests pass
* Update the changelog
* Add a version number to the application
* Create the `v1.0.0` Git tag

## Possible future work

These features are not required for version 1.0:

* Recurring tasks
* Task priorities
* Tags and categories
* Weekly and monthly summaries
* Data export
* Configuration file
* Graphical interface
* Web interface
* Synchronisation between devices

Larger additions should be developed as a separate second phase after the command-line version is complete.
